¿Qué es?

Mi trabajo de sueños es ser Desarrollador de Software. Desde que empecé a estudiar Ingeniería en Desarrollo de Software me di cuenta de que programar es algo que genuinamente me gusta y me llama mucho la atención. Hay algo especial en ver cómo una idea se convierte en algo funcional gracias al código que tú mismo escribiste.

Razones para elegirlo

  • Me gusta mucho programar y es algo que disfruto hacer desde que empecé la carrera.
  • Me llama mucho la atención poder crear cosas funcionales desde cero usando código.
  • La Ingeniería en Desarrollo de Software me ha demostrado que es el camino que quiero seguir.
  • Alta demanda laboral a nivel global y excelentes salarios.
  • Libertad de trabajar de forma remota desde cualquier lugar del mundo.
  • Permite combinar creatividad con pensamiento lógico y analítico.
  • Posibilidad de emprender y crear mis propios productos digitales.
  • Aprendizaje constante: la tecnología siempre evoluciona.

Pasos y requisitos para obtenerlo

Paso Descripción Tiempo estimado
1 Aprender HTML, CSS y JavaScript básico 3 meses
2 Dominar un framework front-end (React, Vue) 4 meses
3 Aprender back-end: Node.js, bases de datos (SQL/NoSQL) 5 meses
4 Construir proyectos reales y armar un portafolio 3 meses
5 Aplicar a empleos, prácticas o freelance Continuo

Resumen explicativo

Sección: Descripción (#descripcion)

Elemento HTML: <p> para el párrafo descriptivo y <span class="highlight"> para resaltar el nombre del trabajo de sueños.

CSS aplicado: Selector de ID #descripcion p con font-size y color. Selector de clase .highlight con color: var(--accent) y font-weight.

Sección: Razones (#razones)

Elemento HTML: <ul> lista no ordenada con cinco elementos <li class="razon-item">.

CSS aplicado: Selector de clase .razon-item con background-color, padding, margin y width: 100%. Hover con transform.

Sección: Tabla (#requisitos)

Elemento HTML: <table> con <thead>, <tbody>, <th class="tabla-header"> y <td class="tabla-celda">.

CSS aplicado: Clase .tabla-header con background-color, color y padding. Clase .tabla-celda con padding y border-bottom. width: 100% en la tabla.

Sección: Imagen (#galeria)

Elemento HTML: <img class="imagen-principal"> con atributos src y alt. <p class="caption"> para el pie de imagen.

CSS aplicado: Clase .imagen-principal con width: 100%, height: 320px, object-fit. Clase .caption con margin-top y color.

Elementos globales (header, main, body)

Elementos HTML: <header>, <main>, <footer>, <section>, <div> para agrupar contenido.

CSS aplicado: body con background-color y color. main con margin: 0 auto y padding. header::before con width y height de 500px. Variables CSS con :root.

Clase global: .tag

Elemento HTML: <div class="tag"> en el encabezado.

CSS aplicado: Clase .tag con padding, margin-bottom, color y border. Demuestra el uso de selectores de clase aplicados a elementos de agrupación.
